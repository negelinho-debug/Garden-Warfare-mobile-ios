# Garden Project v0.3 — плавный 3D-Горохострел

В этой версии включена **оригинальная созданная процедурно 3D-модель Горохострела** (`assets/models/peashooter.glb`): отдельная мордочка, круглые глаза, зелёные листья, стебель, корни, рельеф и другие детали. Это НЕ экспорт из Android APK и НЕ готовая модель из оригинальной Garden Warfare.

Код игры из v0.2 сохранён: главное меню, сад, прогулка с камерой от третьего лица, сенсорное управление, стрельба и мишени, обучение, настройки.

### Честные ограничения
- Сад всё ещё частично процедурный: дом, заборы и дорожки используют прямоугольные детали.
- Герой **не сделан из кубов**, но художественное качество и анимации оригинальной Garden Warfare пока недостижимы.
- Сборка в движке и работа на iPhone **не проверены**. Это проект Godot 4, НЕ IPA.
- Извлечённые из APK модели пока не добавлены; их экспорт требует специальных инструментов и прав на использование в публикации.

### Как использовать
Откройте файл `project.godot` в Godot 4.4, затем запустите проект. Скрипт `scripts/model_loader.gd` автоматически загружает `assets/models/peashooter.glb`.

Собирать IPA сейчас необязательно: сначала проверить импорт модели, ошибки скриптов и внешний вид.
