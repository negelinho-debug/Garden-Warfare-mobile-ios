# Garden Warfare Mobile — v0.4 (прототип)

Настоящий Godot-проект: меню, сад, оригинальная округлая GLB-модель Горохострела,
тренировочные мишени, движение, стрельба и прыжок. Сейчас нет мультиплеера.

Что изменилось в v0.4:
- Игровой сенсорный ввод распознаёт разные пальцы одновременно (ходьба, стрельба, прыжок, камера).
- Исправлена раскладка HUD и счётчика попаданий на широком экране iPhone.
- Стрельба ориентируется на центр камеры, чтобы лучше попадать по близким мишеням.
- При попадании показывается небольшой эффект, поправлен пересвет сцены.
- Камера сохранила тот же алгоритм поворота, который понравился в v0.3.

Ограничение: это не оригинальные модели EA и не графика полной GW1.
Модели из стороннего APK здесь не используются.

Для Godot 4.4.1: `project.godot`, стартовая сцена `scenes/main.tscn`.
Для сборки неподписанного IPA используется отдельный GitHub Actions workflow.
