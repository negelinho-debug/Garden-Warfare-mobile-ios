Garden Warfare Mobile - Visual Update 0.5
==========================================
Обновление только для установленного проекта 0.4.
Камера, сенсорное управление и GLB-модель остаются из 0.4.

Что нового:
- Созданные с нуля текстуры травы, земли, дерева, камня, штукатурки и черепицы.
- Новый дом с двускатной крышей, окнами, крыльцом и гаражом.
- Дорожки из брусчатки, кусты, цветники, более пышные деревья и удалённые холмы.
- Обновлённые тренировочные мишени и вывеска, реакция на попадания.
- Новые авторские синтезированные WAV звуки выстрелов и попаданий.
- Густая низкополигональная трава в одном MultiMesh.

Установка:
1. Загрузить ZIP Garden_Visual_v0.5.zip в корень репозитория GitHub.
2. В .github/workflows/validate.yml вставить Update Garden Game v0.5 workflow.
3. Запустить Update Garden Game v0.5. Сборка валидирует Godot.
4. Если успешно, запустить прежний Build Garden Warfare IPA.

Важно: проект самодельный, не содержит Frostbite/оригинальных ассетов EA.
Перед тестом FPS и рендера на iPhone не гарантируется.
