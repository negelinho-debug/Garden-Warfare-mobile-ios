Required file for automatic player replacement: peashooter.glb
Optional future characters: sunflower.glb, cactus.glb, browncoat.glb

IMPORTANT: No 3D models have been exported from the supplied APK. The
previously supplied Unity package holds proprietary content; this starter
project DOES NOT include or distribute any such content.

After a permitted .glb model is present, Godot 4 imports it as a scene.
The player script loads it instead of the temporary procedural model.
Scale and orientation may need adjustment for a specific export.
